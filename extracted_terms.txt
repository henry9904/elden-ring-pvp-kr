[## 🪄 주문]
| 금지 주문 | 사유 |
|-----------|------|
| **인력탄** | 게임 내 독보적인 성능을 자랑하며, 유일한 실질적 대응 수단이 마찬가지로 금지된 전회 '참기'뿐이다. 또한 상대방 화면에서 위치 정보가 일치하지 않는 비동기화(desync) 현상을 매우 자주 일으킨다 |
| **밤 무녀의 안개** | 일부 시스템에서 프레임레이트를 심각하게 떨어뜨릴 수 있다 |
---

[## 💎 탈리스만]
| 금지 탈리스만 | 사유 |
|---------------|------|
| **도가니 날개 및 모든 도가니의 탈리스만** | 구르기 무적 프레임 증가로 회피를 지나치게 안전하게 만든다. 특히 높은 레이턴시에서 많은 실수들이 처벌받지 않으며, 방어력 저하를 능가하는 효율을 보인다 |
| **도가니 얇은 날개의 탈리스만** | 백스텝 무적 프레임을 과도하게 늘려 일부 레이턴시에서 무적 프레임이 겹치는 것을 허용한다. 느린 공격에 반응하여 라비올리 백스텝을 가능하게 하여, 탈리스만 하나만으로 느린 세팅을 완전히 카운터칠 수 있어 메타 다양성을 감소시킨다 |
| **양손검의 탈리스만** | 양손 공격에 10% 데미지 상승을 적용한다. 메타 세팅 중 일부에만 과도한 데미지 증가를 부여하여 건강하지 않다. 탈리스만이 없으면 다양한 양손, 쌍수, 좌수 기반 세팅이 경쟁하지만, 가장 강력한 세팅에 10% 버프가 더해지면 다양성이 사라진다 |
| **단검의 탈리스만** | 치명타 데미지를 크게 증가시킨다. TTK 유지를 위해 금지된다 |
| **창의 탈리스만 (소드 랜스 한정)** | 소드 랜스의 이미 높은 기본 데미지와 중립에서 딜교를 강제하는 능력 때문에, 딜교에서 현재 메타 기준 과도한 데미지 증가를 적용한다 |
| **붉은 날개 칠지인** | 낮은 체력에서 지나치게 강한 데미지 버프를 적용하여 지고 있던 플레이어가 매우 빠르게 역전할 수 있게 한다. 지고 있던 플레이어가 붉은 칠지인 범위에 진입하면 상대를 20% 적은 상호작용으로 처치할 수 있을 뿐만 아니라, 상대방의 청색 칠지인 범위마저 건너뛸 수 있어 전체 상호작용 횟수를 추가로 20% 줄인다. 이 정도 변동성은 경쟁적 무결성을 심각하게 해친다 |

[## 💨 전회 (AoW)]
| 전회 | 사유 |
|------|------|
| **사냥개의 스텝 (BHS)** | 구르기보다 적은 무적 프레임에도 불구하고 "누를 때" 1프레임 무적이 시작된다. 구르기가 "뗄 때" 시작되어 약간의 딜레이가 있는 것과 달리 즉각적이다. "빠른 전회"로 분류되어 확정 콤보 탈출과 후딜 캔슬에도 더 효과적이다. BHS의 이동 거리 덕분에 평범한 구르기를 추적할 공격도 빗나가게 만든다 |
| **퀵스텝** | BHS와 동일한 이유. "누를 때" 1프레임 무적, "빠른 전회" 분류로 후딜 캔슬이 빠르다 |
| **안개의 맹금** | BHS와 모두 같은 이유로 금지된다. 다만 점프 공격을 위해 사용자를 공중으로 올려놓기 때문에 기능 방식은 다르다. 웅크리기로 취소 후 재사용이 가능하여 높은 레이턴시에서 무적 프레임을 쉽게 겹친다 |
| **사각에서 일격** | BHS/퀵스텝과 유사하게 후딜을 취소하는 무적 프레임이 있는 매우 안전한 공격이다. 공격의 사거리 때문에 헛스윙을 응징하는 것 자체가 비현실적이다 |
| 전회 | 사유 |
|------|------|
| **염격** | 잔류 히트박스로 인해 중립에서 대부분의 근접 공격에 사실상 처벌받지 않는다. 딜교 시 레벨 2 경직으로 항상 상대에게 불리한 딜교 콤보를 세울 수 있으며, 낮은 FP 소모로 한 결투 내 수십 번 안전하게 스팸할 수 있다. 잔류 히트박스와 높은 데미지로 구르기 캐치와 확정 콤보 연계까지 가능하다 |
| **속참 (빠른 베기)** | 상대방이 발동을 끊지 않는 한 프레임 트랩으로 항상 데미지를 보장한다. 전회가 온전히 적중했을 때 극도로 높은 데미지를 입혀 나머지 메타 대비 엄청나게 과도한 성능을 낸다 |
| **남각** | 헛스윙 응징 시도에 이기는 딜교를 쉽게 취하는 빠른 하이퍼아머, 처벌을 매우 어렵게 만드는 잔류 히트박스, 구르기 캐치 도구로서의 활용까지 가능하다. 낮은 FP 소모로 전투 내내 끊임없이 스팸하기 쉽다 |
| **폭풍의 습격 / 폭풍 부르기 / 붉은곰의 사냥** | 매우 빠른 하이퍼아머 시작, 크게 이기는 딜교에서의 높은 데미지를 가지고 있으며, 잔류 히트박스로 인해 응징이 매우 어렵다 |
| **야만적인 포효** | 이를 사용하는 세팅의 강공격 체인을 특대 무기 공격도 강인도로 버틸 수 있는 빠르고 높은 데미지의 공격으로 변경한다. 특히 가시 철구권에서 강력한데, 중간 타격을 강인도로 버티는 것이 가능하지만 그것이 강인도 깎기 반복을 허용하기 때문에 오히려 처벌을 받게 된다 |
| **침 찌르기** | 팬텀 히트에서조차 대상의 모든 버프를 제거할 수 있다. TTK 관리를 위해 결정 물방울에 의존하는 규칙의 특성상 게임플레이를 지나치게 왜곡한다 |
| **통타 (이빨 채찍의 전회)** | 강인도 깎기를 설정하면 단검 속도의 높은 데미지 전회가 좌수로의 확정 콤보로 이어진다. 좌수 도끼와 함께라면 후속타를 통해 강인도 깎기를 반복할 수 있다 |
| 전회 | 사유 |
|------|------|
| **모든 패리** | 헛나간 패리를 응징할 수 있는 최대치가 프레임 이점에 불과할 정도로 후딜이 극도로 짧아, 위험 대비 보상이 지나치게 크다. 많은 세팅 패리들이 딜교를 강제할 상황에 대한 리딩만으로 원샷에 가까운 보상을 가져온다. TTK 증가 조치들이 오히려 패리의 가치를 더욱 높인다 |
| **참기** | 발동 중 방어력과 강인도 증가로 모든 압박을 무효화하고, 끝날 때까지 크게 불리한 딜교를 취하지 않도록 상대를 물러서게 강제한다. 결투에서 기술 발휘의 많은 경로를 원천 차단한다 |
| **복수의 맹세** | 참기와 동일한 문제지만, 60초 동안 모든 능력치를 5 상승시키며 더 오래 지속된다. 어떤 행동이든 안전하게 설정할 만큼 지속 시간이 길어 치사한 전략에도 활용된다 |
| **도읍 기사의 결의** | 다음 타격에 40% 데미지 버프를 적용한다. 후딜이 낮아 재적용이 매우 쉬워 사실상 단점 없는 데미지 버프로 TTK를 줄인다 |
| **디터미네이션** | 다음 타격에 30% 데미지 버프를 적용한다. 도읍 기사의 결의와 같은 이유로 금지된다 |
| **비통한 외침** | 낮은 체력에서 최대 20%의 데미지 상승에 도달하는 버프로, 사실상 두 번째 붉은 날개 칠지인으로 작용한다. 건강한 TTK를 유지하기에는 데미지 증가가 지나치게 크다 |
| 전회 | 사유 |
|------|------|
| **냉기 안개 (냉기 변질 무기 한정)** | 어떤 빌드의 어떤 세팅에서든 3타 냉기 발생으로 상대에게 20% 방어력 디버프를 적용하고 더 높은 데미지 변질로 교체하여, 한 전투에서 여러 번 이끼약 시도를 쉽게 적용하고 응징할 수 있다. 카운터플레이는 상태이상/버프가 끝날 때까지 지연하거나 미러링하는 것으로 귀결된다 |
| 전회 | 사유 |
|------|------|
| **검무 소형무기 (빠른 검무 애니메이션 사용 세팅 한정)** | 빠른 하이퍼아머 시작, 좋은 데미지, 일관되게 구르기 어려운 공격으로 헛스윙을 유리한 하이퍼아머 딜교로 쉽게 덮을 수 있어 전투 내내 스팸하기에 매우 안전하다. *(참고: 샴시르가 빠른 검무 애니메이션을 사용한다)* |

[## 💨 전회 (AoW) — 3회 제한 규칙]
- 라운드 내 어떤 전회든 **3회 초과 사용 시 라운드 패배** 처리
- 전회 **시전 중 끊겨도** 사용 횟수로 카운트된다
- 전회의 **후속 동작은 추가 카운트 없음** *(예: 끊기지 않은 연속 폭풍의 칼날 입력, 염격 후속 타격 등)*
| 예시 | 카운트 |
|------|:------:|
| 염격 L2 1회 사용 | 1 |
| 염격 R2 후속 타격 | 0 *(후속 동작)* |
| 폭풍의 칼날 3회 연속 입력 (끊기지 않음) | 1 *(1회 사용)* |
| 시전 중 끊긴 경우 | 1 |
| 어떤 전회든 4번째 사용 | ❌ 라운드 패배 |
- **토너먼트** — 양쪽 플레이어와 TO 모두 카운트. TO의 판정이 최종
- **래더** — 녹화를 권장. 양쪽 모두 녹화가 없으면 분쟁은 무시된다
