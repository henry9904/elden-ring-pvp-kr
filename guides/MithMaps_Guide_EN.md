# 🗺️ MithMaps Guide

> [!NOTE]
> **MithMaps** is a custom Elden Ring mod that supports 2v2 and 3v3 battles. This document is based on the official guidelines.

## 🛠️ Installation & Setup

- **Launch**: Use the `Launch MithMaps.bat` file to open the mod.
- **Changing Password**: To change the password, use the seamless folder within **MithMaps**, NOT the DEN1 folder.
- **File Extension**: The mod uses the file extension `.mith`, which can be added in:
  `C:\Users\YOUR-PC'S-NAME\AppData\Roaming\EldenRing`

## 🎮 Features (by Molly)

- **Teams**: 2 team types (Red and Blue team).
- **Respawn Points**: Custom setable respawn points.
- **Scoreboard**: An in-game scoreboard.
- **Kill Script**: Built-in kill all mobs script.
- **Invasions**: 
  - Invasions now work with only other people that have the mod.
  - Invaders are now red instead of colorless like on seamless. 
  - All vanilla areas + custom areas are invadable (This can be disabled in the seamless settings in the folder within MithMaps).

## ⌨️ Hotkeys

| Hotkey | Action |
|---|---|
| `F1` | Join Red Team |
| `F2` | Join Blue Team |
| `F3` | Leave the Team (needed to use separation mist) |
| `F4` | Show Score |
| `F5` | Clear Score |
| `F6` | Set Custom Respawn Location |
| `F7` | Kill All Mobs |
| `F8` | Toggle Player List |
